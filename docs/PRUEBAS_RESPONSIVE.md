# Pruebas responsive – Pedidos360

## Objetivo

Verificar que la interfaz de Pedidos360 se adapte correctamente a diferentes resoluciones de tablet, manteniendo la legibilidad y funcionalidad de sus componentes.

## Entorno de pruebas

- Aplicación: Pedidos360
- Frontend: React y Vite
- Herramienta: DevTools del navegador
- Modalidad: Simulación de dispositivos

## Resoluciones de referencia

| Dispositivo | Resolución |
|---|---|
| Tablet vertical | 768 × 1024 |
| Tablet horizontal | 1024 × 768 |

## Criterios de validación

- Navegación visible y funcional.
- Botones accesibles.
- Formularios adaptados al ancho de pantalla.
- Tablas y contenidos sin desbordamientos.
- Textos legibles y sin superposiciones.

## Resultado

La revisión inicial de la aplicación no identificó problemas visuales o funcionales que requirieran modificaciones en el frontend.

## Conclusión

No se consideran necesarias correcciones responsive a partir de la revisión inicial. Se recomienda repetir estas pruebas cuando se incorporen nuevas pantallas o componentes.
